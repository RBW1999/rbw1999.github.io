# Project Gamma

Project Gamma is an open-source design system that helps teams build consistent, accessible web applications faster.

## Philosophy

Great design systems are invisible. They provide the building blocks so teams can focus on solving user problems instead of debating button styles.

## What's Included

- **40+ components** built with Vue 3 and Tailwind CSS
- **Design tokens** for colors, typography, spacing, and elevation
- **Accessibility-first** — every component meets WCAG 2.1 AA standards
- **Documentation site** with live examples and code snippets
- **Figma library** that stays in sync with the code

## Adoption

Project Gamma is currently used by three production applications and has 200+ GitHub stars. Contributions are welcome — check the repository for guidelines.
